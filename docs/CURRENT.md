# 当前采用的实现

本项目只有一套当前有效实现：已完成取舍和集成的 CPU/GPU 混合两方隐私计算组合。这里的“当前最优”指本机有限比较后采用的组合，不是对所有算法或硬件的全局最优证明。必要 CPU 分支属于该组合，不能因整理目录而删除。

## 实现与证据

- Token：设备驻留、双坐标流水；单槽1024维与四槽2048维使用本方 GPU 环内积/精确缩放，其余公开形状保留 CPU。
- 矩阵：GPU NTT、选择性系数回传、多输出组流水；指定 QK/PV 形状使用 GPU 输入加密，QK 使用 GPU 返回相位，返回 Enc(0) 的确定性算术使用 GPU。
- SiLU：精确仿射残差电路，公开批量2048～6144使用分段 GPU；其他批量使用 CPU。范围与截断融合、16行 SwiGLU 批处理、矩阵三元组组织和63 AND解码保持已采用实现。
- 随机材料、身份授权、TLS、账本、必要读取与检查继续承担各自协议职责。新鲜材料不得跨会话复用。

详细适用范围、采用和排除理由见 [优化说明](OPTIMIZATIONS.md)。本页只描述现行方案，不把退役候选列为可选部署版本。
