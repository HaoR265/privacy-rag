# 已采用的等价算子优化

优化服务于两方隐私计算实现，保持模型修订、层数、固定输入输出预算和隐私边界。未通过秘密重构执行明文模型，未裁剪模型，也未改变规定的 floor 顺序。

## 私有 Token 查表

1. **单槽 GPU 路由**：单槽接口使用既有 B=1 GPU 后端，保留原接口、描述符和一次性材料次序。实现位于 `native/src/bfv_token_api.inc`。
2. **GPU 驻留密文打包**：一对分支连续完成移位、加减、Galois 变换及两次独立换钥，减少一次设备回传。保留完整系数和规范化处理，不改变噪声界。实现位于 `native/src/bfv_gpu_packing.hpp` 及 `experiments/keyswitch_full_gpu/`。
3. **有界坐标流水**：一个辅助线程准备下一坐标的只读权重和本方环点积；主线程保持原 GPU、网络和材料次序。仅显式声明线程安全的 reader 可用；使用两个主机缓冲区，不新增 GPU 分配。异常退出需回收线程和清理缓冲区。实现位于 `native/src/token_coordinate_queue.hpp` 和查表引擎。

## 其余已集成算子

主库还包含精确 BFV 矩阵 GPU 运算、适用形状的逆向打包及选择性系数回传、逻辑矩阵三元组组织、精确 SiLU 仿射表达与范围／截断融合、16 行 SwiGLU 批处理、BFV 普通解码的 63 AND 组织及 BFV 标签批量生成。标签批量生成仅影响 BFV 相关代码，不代表通用 SiLU 混淆电路获得同样收益。各路径适用条件由源码检查，未核对的形状不能套用局部性能结果。
