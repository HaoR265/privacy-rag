# 已批准SwiGLU联合输出域的独立整数复核

本记录只复核上游SiLU与up输出均已检查在±256、f12时，联合输出允许±65536的局部修订。没有把该修订延伸为down输出、残差或RMS输入的新域。实际文件及每层结果见numeric_swiglu_review.json，可由tools/build_crypto_swiglu_review.py独立重算；这是实施依据，不是正式验收标准。

若A、B是f12编码的已检查SiLU及up值，则|A|、|B|≤2^20，故|AB|≤2^40。floor(AB/2^12)的两个极端恰为±2^28，因为端点可被2^12整除；因此无需凭空增加一个负数floor误差。联合输出f12的绝对域2^28对应实数65536，原始逐项乘积严格小于2^56。

独立代码核对了两份当前manifest哈希、全部56个down_proj.npy文件哈希和形状，并逐行以int64分块精确计算绝对值和。候选中每层最大行L1、首个最大行索引和最大绝对权重全部一致。Embedding的全层最大行L1为2136368，Generation为2160211。联合域2^28乘这两个L1分别为573476918263808、579877224841216，都严格小于2^56。对任意完整点积、BFV输入块及任何有符号部分和，三角不等式使用同一行绝对值和，故同一上界成立。

这个结论只保证联合值进入down线性时的中间整数预算，不保证down输出≤256。实际固定floor12后的一般绝对界分别达140009013248和141571588096个f12整数单位，远超256的f12域；观测到down离群不能被这项L1证明消除。后续普通激活和残差/RMS域必须独立处理，未在本记录中变更。

机器具备RTX2060，但当次已安装torch2.6.0+cu124初始化CUDA返回unknown error、is_available为false。没有为复核改动用户GPU环境，改用64行CPU整数分块，避免将设备存在当成密码或整数扫描GPU后端已可用。复核没有运行完整模型或证明质量。
