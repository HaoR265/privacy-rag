# ART-002：锁定 BFV 实例的条件性解析解码界

这是实施代理从锁定源码推导的数学证据；不是用户批准的验收规范，不以小规模运行替代证明，也不宣称软件或完整协议已获得安全认证。实际参数见 `artifacts/bfv_context.json`，整数计算与源文件哈希见 `artifacts/bfv_correctness_bound.json`，由 `tools/build_crypto_evidence.py` 重建。

## 符号与源码语义

令 n=16384，t=2^59，密钥层模数 Q_key=pq，p 为最后一个60位素数，q 为实际第一数据层六个素数之积。后端固定在这个数据层，不继续降模。每个返回密文在同一数据层汇总 K 个密文与明文多项式乘积（1≤K≤512），之后只执行一次全多项式掩码减法和一次独立 Enc(0) 加法。每至多512目标统一作一次GC进位修正，不逐坐标运行完整联合除法。

锁定 SEAL `119dc32e135cb89c1062076a69310d4413ebc824` 的 `util/rlwe.cpp::sample_poly_cbd` 取两组21位汉明重量之差，因此每个噪声系数严格在[-21,21]；`sample_poly_ternary` 的 s、u 系数在{-1,0,1}。构建固定 `SEAL_USE_GAUSSIAN_NOISE=OFF`，`defines.h` 选择CBD。这一论据依赖实际构建配置，不能挪用到任意SEAL构建。

在密钥层，公开密钥相位为 -e_pk，非对称零密文的相位为 -e_pk*u+e0+e1*s。负循环多项式卷积每系数至多n项，故其绝对值不超过 E_key=21(2n+1)=688149。

`encryptor.cpp::encrypt_zero_internal` 对每个密文分量执行 `rns.cpp::divide_and_round_q_last_inplace`，再丢弃p。逐分量除p取最近整数相当于加入系数绝对值至多1/2的舍入量 r0、r1。相位误差为 E_key/p+r0+r1*s（模q），故存在中心代表满足

E_zero <= 688149/p+(n+1)/2 < 8193.

模q代表选取不影响后续关于环上相位的等式；该界远小于q/2。

## 一次私有线性与受保护返回

`scalingvariant.cpp::multiply_add_plain_with_scaling_variant` 嵌入每个明文m为 round(q*m/t)，与(q/t)*m的偏差绝对值至多1/2，且这里对任意m∈[0,t)成立，覆盖均匀随机的输入份额。

本工程对私有W采用固定形状的完整RNS提升、NTT、逐点乘、逆NTT。它刻意不调用SEAL根据明文非零个数选择的常量/单项式优化；每个W系数提升到[-2^58,2^58)。因此，即使不借用更严格的模型f12权重域，W的系数L1范数也至多 L=8192*2^58=2^71。

第 b 块输入相位乘 W_b，各块在同一 q 层直接相加，然后减去 round(qR/t)、再加一次独立 Enc(0)；目标明文结果为 (Σ_b W_b*X_C,b−R) mod t。同层模 q 加法没有新舍入。与该结果理想(q/t)倍数的圆周误差严格小于

B_K = 8194*(K*L+1), 1≤K≤512.

因为误差逐项由 (8193+1/2)*Σ_b||W_b||_1、1/2、8193 覆盖，且每块 ||W_b||_1≤L。最终 mask 和 Enc(0) 的常数贡献只出现一次。K=1 恰回到历史 B_1=8194*(L+1)；不需要各块噪声独立。Token兼容路径的 K=19 时 B_19=367603174126021792369745922，2*t*B_19+1=423817604611625804982080960099786874654031873，严格小于实际360位 q。现行矩阵路径最多512块，B_512=9905938165922271457542414338，同样以实际q验证4*t*B_512<q。W为零时同一不等式成立，同一掩码/重随机化/GC路径执行。模型域 |W_real|<=256 且f12给出更小界，但不是此密码解码结论的必要条件。

## 精确整块受控解码与会话界

当前 v1.0.8 的完整解码定理、份额和隐私论据见 crypto_tile108_implementation.md。C 与 S 分别对自己的 u 与 c0 用 GMP 精确 divmod(t*component,q) 求高部 A/B 和余数 a/b。由上面的圆周误差界及实际4*t*B512<q，a+b距整数k∈{0,1,2}小于1/4。两位区间即可精确恢复该进位；GC只向C输出k-rho，绝不公开k或联合相位。

每tile一个GC，122T个AND及2T个选择位的独立IKNP输入批次；C得A+k-rho，S得WX_S+R+B+rho。和为WX，尺度和后续floor位置不变。每坐标rho全环均匀，原全多项式R与fresh Enc(0)保留。此处更强的4*t*B512<q同时蕴含最近整数解码正确性，没有近似除法或新增数值误差。

有界采样下每目标噪声引发的失败概率为0，任意有限会话并集仍为0，满足2^-64目标。此结论以前述锁定源、操作次数及诚实执行为条件；不包含模型算术回绕、硬件故障、代码错误或整体安全认证。
