# 批量共享数值内核：实施候选

当前状态：批量共享内核、完整 RMS 和单个注意力头已形成实现及有限运行证据，见 `batch110_implementation.md` 与 `batch110_stage.json`。16×1280头的正式 OT 路径在共享 QK 阶段300秒未完成。另一个 BFV 矩阵预处理候选单独登记在 `matrix_triple_bfv_candidate.md`，尚未启用。v1.0.9 的源文件和证据保存在 `v109_source_snapshot.tar.gz`，旧记录不改写。

目标依赖：固定形状共享数值内核 → 完整 RMSNorm → 共享矩阵 QK/PV 与 Softmax → 单层、Decode。最终 R2 GPU 执行门禁仍关闭；SEAL/SCI 独立密码内核允许 CPU 核对，所有模型参考计算使用 RTX2060。

选择：沿用 SCI 的 IKNP、Half Gates 和 Z_(2^59) 加法份额。把同一公开批次的 A2B、范围判断、选择、精确 floor、指数抽取、带越界检查的秘密移位放入固定形状 GC；乘法采用现有真实 OT Beaver 批次，gamma 采用现有 S 私有对角乘法。不是只合并通信帧。GC 内加合两方输入的线值属于安全电路，不产生主机明文；结果减去 S 的新鲜完整环掩码后才解码给 C，错误位以新鲜 XOR 掩码输出。

每次操作先交换并核对公开操作码、形状、尺度和参数描述符，登记一次性材料；每个 GC 使用新 delta 和标签，IKNP 流仅在同一会话内前进，失败关闭并烧毁预留材料。固定上限 B≤16，d≤2048；平方和节点加法前检查剩余额度。所有行失败保持秘密、整行安全替代、固定调度。

RMS 语义不变：坐标检查 → 平方 → 加法前检查平方和 → 整行失败替代 → floor(sum/d)+16 → 秘密指数/尾数 → 六轮 NR（原有每个 floor 位置）→ x 归一化 → S 私有 gamma → floor 和输出检查。非负平方和可用平衡树：每个节点超过额度就标错并安全替代；根错误恰好等价于任意坐标失败或真实总和超过上限。发生错误时输入向量和总和都归零；未失败时得到同一个精确整数和。节点计算界由 2*(limit+1)<2^56 保证。

计量只记录公开阶段、时间、应用层字节、帧数、方向转换、内存峰值、OT/Beaver/GC 预留数量；方向转换不是网络 RTT。旧标量路径采用短诊断截止，不为补齐报告延长到不可行时长；未到达的阶段明确记录。新路径运行后另存来源、二进制、CUDA 参考和材料账本哈希。以上不是正式测试或验收规范。
