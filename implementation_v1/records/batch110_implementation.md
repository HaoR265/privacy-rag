# v1.0.10 批量共享数值实现依据

这是工程实现与局部正确性说明，不是形式安全审计或正式验收规范。执行证据由 `batch110_stage.json` 汇总，只有其中来源和库哈希匹配当前代码的记录才表示当前实现实际运行过。完整层、完整 Decode 和完整 R2 仍未运行；CPU SEAL/SCI 内核不是私有 GPU 后端。

## 接口与依赖

| 模块 | 输入与形状 | 输出、尺度及保密状态 |
| --- | --- | --- |
| BatchOps GC | C、S 各自的模 2^59 算术份额及 XOR 位份额；公开操作码、行列、参数；每批最多32768个逻辑坐标 | 新鲜算术/XOR份额；Range、Floor、Compare、Select、A2B/B2A、OR、Exponent、Shift、GuardedSum、公开 LUT、Softmax/exp 准备 |
| BatchOps multiply | 两个同长共享向量，最多32768项 | 一次性OT Beaver，批量公开掩码差；同环乘积，尺度相加；没有原份额交换 |
| BatchOps matrix | X[B,K]、Y[K,O]都是共享输入，B≤16，K/O≤1280；公开尺度及完整/任意部分和界<2^56 | X·Y[B,O]共享原始整数，不在分块内截断；256个输出坐标一组，至多32768个乘积一批 |
| RMS | B≤16，d∈{128,1024,2048}的f12共享向量；S私有f12 gamma[d]；公开输入/输出范围 | f12共享结果及秘密失败位，全部检查和六轮NR保持原语义；gamma每8192坐标一个私有对角OT块 |
| Attention | 共享Q[B,128]、K[L,128]、V[L,128]，L≤1280；共享允许位和查询有效位 | QK先floor12，再乘92681并floor20；Softmax为f24；PV完整累加后floor24，查询无效时置零并检查f12主干范围 |

模型输入/FFN/最终归一化按公开最多16行分块；Q/K头先按公开行、头次序整形成128维行，再分块执行。所有物理位置继续运行。Attention同样逐公开头、最多16个查询行分块；K/V和逻辑因果条件的来源不变。

## 表示与安全电路

采用锁定SCI提交的HalfGateGen/HalfGateEva、独立IKNP流和现有TLS1.3 mTLS Channel。GC的S输入包含S的算术/布尔份额及每个输出的新鲜掩码；C输入标签经OT传递。59位加法器只在电路内合并输入份额，丢弃最高进位，实现模环A2B；不在主机恢复输入。S生成每个算术输出的均匀59位rho，在电路内对完整结果减rho；仅C解码差值，S保留rho。布尔结果同样与S的新鲜随机位异或。旧标量OT B2A仍存在；批量B2A在电路中把XOR位组合成整数，再按上述方式重新分享，两者输出表示相同。

每次电路新建delta、公共标签、输入标签、哈希状态；会话内独立IKNP流连续推进。公开拓扑计数执行相同循环以精确计算AND数，但不读取操作数或计算模型输出。真正执行必须消费完全相同数量的Half Gates，否则中止。表查找的分支仅依赖公开表常量。

`PRAGBAT1`描述符共64字节：8字节magic，7个大端uint64（版本1、操作码、rows、cols、三个公开参数）。同现有PRGCF001帧绑定session/configuration/stage/operation/sequence。公开256项LUT再交换其2048字节小端uint64编码的SHA256；不同表拒绝。每次调用先登记描述符、GC AND、输入OT及新鲜输出掩码数量，再消费材料。形状错误、参数不一致、对端断线和协议异常关闭会话；既有O_EXCL账本防止重用路径，全部预留永久烧毁。

外部API不能绕过半诚实假设：这些检查不是恶意安全证明。普通参数/输入格式错误允许公开拒绝；数值域失败留在秘密标记中，不能改变公开调度、消息长度或输出尺寸。

## 精确整数语义

比较使用逐位进位判定a>b，签名比较先翻转最高位；不是看差值符号。Floor由电路内A2B、有符号右移和重新分享组成，对负数向负无穷取整。移位沿用原秘密方向、绝对移位量、32位上限和严格|整数|<2^56判断。将原128根线缩为91根：59位输入最多左移32位，最高真实符号位置为90；更高位始终只是相同符号的重复，删掉重复相等检查不改变判定。恰好−2^56仍拒绝；移位量越界仍选择0移位并累计秘密失败，与原实现一致。

平方前先检查坐标并把失败坐标换零。每个平方是非负且≤L。树节点先计算room=L−left，秘密判断right>room，选择安全right后才相加，节点结果始终≤L。任一节点超限或坐标失败都累计到行失败，最后把整行值与平方和一起置零。若未失败，树求得精确总和；若真实总和>L，任一树分解必有子树或根超限。因此其行接口与原顺序扫描等价。两个子节点的原值之和也严格小于2^56（RMS最大2*(L+1)<2^54），但实现仍在加法前选择，不借此省略预算检查。

RMS保持 `floor(sum/d)+16`、指数范围[-10,8]、初值1/2和六轮NR；每轮所有floor位置保持。缩放输入检查96 f24，随后乘y、floor24、floor12、乘私有gamma、floor12、输出范围检查，顺序不变。错误行选正分母dummy，全部后续步骤仍执行。

公开数学LUT在电路内固定生成8层one-hot树。每父节点仅一个AND得到右子，左子是父与右子的XOR；高51位不为零时根置零。因此仅当索引∈[0,255]时恰好一个叶为1，其他情况全零。逐输出位XOR所有表常量相应位为1的叶，与固定全表秘密相等选择求和逐位等价；不使用秘密地址，不省略秘密为零的行。三个8位exp表、两次floor24、32 f12尾部规则、负输入失败规则均保留。

Softmax在电路中处理共享有效位、行最大值和缺失允许键的dummy，未公开最大值、是否有键或任何注意力概率。分母本地完整累加，倒数仍为六轮NR与原floor节点，输出检查[0,1] f24。QK和PV采用共享乘共享OT Beaver，绝不把共享K/V当作S私有权重。QK任意部分和由128·Qcap·Kcap界控制，PV沿用已登记的Σp<4·2^24及V主干域，所以任意部分和绝对值<2^49；批量化不改变这些前提。

## 证据和成本口径

旧v109源码、库、记录已封存，旧300秒RMS结果保持原样。短时旧路径计量在三种维度、B=1/16均实际执行18秒，未到达的NR等阶段不补造数值。新路径每个公开阶段计量实际时间、应用层字节、帧数、转录方向变化、进程峰值RSS及材料数量。时间含本机调度和诊断记录开销，不是网络性能基准；方向变化不是网络RTT。基础OT/GC输入OT、算术OT、Beaver和GC AND分开计数。

v109约10.69TB是其矩阵/Token/gamma子集，不能标成当前完整成本。新增RMS和Attention数据必须另列，并在合计时从旧子集中去除重复gamma。SwiGLU、RoPE、检索、argmax、会话通信等仍未完成当前批量计量，不得填零或据此推导完整运行时间。不得把完整内核成功、文档一致性成功、完整系统成功混为一项。
