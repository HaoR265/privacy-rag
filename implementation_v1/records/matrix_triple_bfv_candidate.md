# 共享矩阵三元组：BFV 交叉项候选

状态：用户已明确同意增加该路径（DEC-015），正式实现见 `batch111_implementation.md`；本文件下表保留候选程序的真实运行身份，不能代替正式路径记录。当前矩阵三元组增加 BFV 预处理；向量/标量 Beaver 继续 OT。没有更换 BFV 参数、密钥归属、环、模型、数值规则或预算。

## 参与方和代数

双方分别独立均匀采样 `A_i[B,K]`、`B_i[K,O]`，元素在 Z_(2^59)。实际模型输入始终是 `[X]` 和 `[Y]`，不作为 S 私有权重提供给 BFV。随机预处理矩阵不受模型定点域约束，也不作 floor。

1. 现有 `private_matrix` 输入分享 `(A_C,0)`，S 私有系数 `B_S^T`，输出 `[A_C B_S]`。
2. 同一原语输入分享 `(B_C^T,0)`，S 私有系数 `A_S`，输出 `[B_C^T A_S^T]`，公开转置成 `[A_S B_C]`。O 行按公开至多16行分块。
3. 各方加本地项 `A_i B_i` 得到 `[T]`，于是 `T=(A_C+A_S)(B_C+B_S)=AB mod 2^59`。
4. 只公开 `D=X-A`、`E=Y-B`，输出 `Z_C=T_C+D B_C+A_C E`，`Z_S=T_S+D B_S+A_S E+DE`。矩阵因子顺序不交换，合并后恰好 XY；完整模块累加后才执行原有 floor。

两次 BFV 调用的密钥均由 C 持有，没有反转解密方。C、S 的随机 A/B 分享使用独立 CSPRNG，三元组和开口材料预留一次后即消耗。随机预处理失败必须中止并烧毁，不能继续或重试复用。候选成功路径清除主随机数组；若进入生产，还需完善所有临时副本的异常清理与公开 ABI 描述符，增加来源登记。

## 条件正确性与隐私

现有 BFV 普通矩阵界允许完整59位环系数，居中系数绝对值≤2^58；候选 K≤1280，B≤16，O≤1280，未超过已证明的 K≤8192、每多项式8192系数及512输入块通用界。因此沿用实际数据层 q、`4tB512<q`、全多项式 R、新鲜 Enc(0)、c1-only 精确 GC 解码和重新分享，不引用小权重专用 Token 界。

在既有半诚实、RLWE、OT/GC 安全假设及现有 private_matrix 安全接口成立的条件下，两个交叉项调用只给各方新的加法份额，不暴露另一方随机矩阵；每次调用独立输出掩码。A、B 含对方独立均匀随机分享，因此 D、E 不泄漏 X、Y。后续 Beaver 公式只用公开差值和本方随机分享，输出仍共享。复用同一 A/B 形成同一个矩阵三元组是代数所需，不能跨乘法调用复用该三元组。固定输入/返回形状由 B/K/O 决定，无秘密分支、稀疏跳过或秘密重构。

这是局部组合论证，依赖已登记原语假设，不是独立安全审计或完整协议证明。有限运行不能证明任意输入正确，也不证明完整模型可运行。
