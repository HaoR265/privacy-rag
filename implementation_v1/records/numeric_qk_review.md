# Q/K 局部数值域修订独立实施复核

本复核只讨论已获用户授权的局部 Q/K 修订的数学与实现前提；不另立测试或验收规范，不替代真实模型运行。历史候选文档中的 PROPOSED 字样保留为当时记录，当前授权与活动版本由主任务维护。复核输入与逐项精确整数结果、实际文件哈希在 `numeric_qk_review.json`。

结论：候选 JSON 的 B、可用 Y、H、两模型 Q/K gamma 后界、RoPE 界、QK 累加与 attention scale 乘法界全部精确重算一致，没有发现推翻该候选的局部数值冲突。实际读取两个模型各28层的 Q/K gamma 共112个量化向量；最大值为 Embedding Q=48384/K=395264、Generation Q=38656/K=278528（均 f12），与候选一致。直接读取真实常数表核对 max(|cos|+|sin|)=1482912（f20）、attention scale=92681（f20）、epsilon=16（f24）。这不是整个模型不触发其他数值失败的保证。

## 均方、尺度与 mantissa 的 floor 边界

记 F=2^24，输入整数 |X_j|≤2^20，d=128。S=sum X_j²≤2^47，A=floor(S/128)+16∈[16,2^40+16]。由于 floor(S/128)>S/128−1，A>S/128+15，因此用于 B 界的 A≥S/128 成立；不能省略 epsilon 后再沿用此不等式。

指数选择产生 k=floor((floor(log2 A)−24)/2)，故严格有 2^(24+2k)≤A<2^(26+2k)，且 k∈[-10,8]。实现为 k<0 时精确左移 −2k 位，k≥0 时 floor 右移 2k 位。因此 M=floor(A·2^(−2k)) 始终满足 F≤M≤4F−1。关键原因是下边界 F 为整数且 A 已不小于精确阈值；floor 不会使 M 落到 F 以下。上边界是严格小于整数4F，因此 floor 仍严格小于4F。

例如最小 A=16、k=−10 给 M=F；最大 A=2^40+16、k=8 也给 M=F，epsilon 的低位在这一步舍去，但 mantissa 仍合法。跨 k 边界时，旧区间的右端给 M≤4F−1，新区间起点给 M=F。JSON 对19个 k 区间的端点以整数移位复算，端点核对支持重现；完整理由是上述不等式，不是有限采样。

B=floor(X·2^(12−k))。由 |X|≤sqrt(128A) 与 A<4F·2^(2k)，有 |X·2^(12−k)|<2sqrt(128)F。负数 floor 最多再增加一个整数单位的绝对值，故候选 B_max=ceil(2sqrt(128)F)+1=379625064 保守成立。B_max 小于96F的原有缩放向量检查阈值。

## NR 可用状态与 H 的界

每轮输入先经过 state 检查/替代，具有 y=Y/F∈[0,2]；m=M/F∈[1,4)。设 U=floor(Y²/F)，V=floor(MU/F)，两次floor给 V/F=m y²−δ，其中 0≤δ<5/F。后续floor只使有符号实数结果更小，因此本轮原始输出 y_next≤y(3−m y²)/2+5y/(2F)。在 y≥0 上，前项全局最大值为1/sqrt(m)≤1，且 y≤2，于是 Y_next≤F+5。

这里必须区分单侧上界与绝对界：任意合法输入 y∈[0,2] 的原始迭代值可能为负，上式不能直接当作其绝对值界。下一次或末次 state 检查会将负数/超域值替代为 F/2；初值和替代值也不超过 F+5。因此传给后续乘法的**可用非负 Y**满足 0≤Y≤F+5=16777221，候选 H 推导所需前提成立。

两次连续整数floor满足 floor(floor(BY/F)/4096)=floor(BY/(F·4096))，包括负数。于是 |H12|≤ceil(B_max·(F+5)/(F·4096))=92682。对应 B·Y 原始整数绝对界为6369053595867144，低于2^56。

本复核绑定的旧 range_evidence 快照中，NR_y_times_correction=18F²，若只援引粗略状态域[0,2]则不够：m趋近4、y=2时绝对值趋近26F²。但是固定初值与上述可达上界还给 Y≤F+5，从而 U≤F+10、V≤4F+38，|3F−V|≤3F，实际原始乘积≤3F(F+5)<18F²。因此该条在本固定执行中成立，但证据应明确依赖可达 Y 不变量；也可保守登记26F²=7318349394477056，仍远小于2^56。这是同一数值设计的证据细化，不要求改变迭代。

## 实现关联与余下边界

上述前提依赖：每次Q/K投影输出仍先检查/安全替代到±256；sum未在2^59环中先回绕；k来自规定的秘密区间选择；gamma与常数哈希对应已读取工件；Q/K两套整数阈值一路区分到RoPE与K缓存。已有公开shape下平方和、B·Y、gamma/RoPE/QK乘法界均低于2^56，能够支撑这些计算前提。

只读检查原 scale_shift 的高位符号扩展逻辑发现它接受[-2^56,2^56)，包含恰好−2^56，与注释的严格 |x|<2^56 差一个边界值；已反馈主任务修正。当前Q/K解析界远离该点，此问题不推翻本候选。

没有据此证明迭代近似误差足以得到某种模型质量，没有保证修订后所有层的主干、残差或MLP留在原域，也没有宣称完整R2已运行。数值规则/版本/实现同步由主任务负责，本复核不改数值语义。
