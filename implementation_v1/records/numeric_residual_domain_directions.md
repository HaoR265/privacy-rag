# 后续整体激活域候选的独立解析讨论（未应用）

本记录回应真实模型除Q/K与SwiGLU外，在down、残差及后段普通归一化输出也越过旧256域的观测。它提供可行的整数预算结构，不批准或实施任何新域。models代理另负责全部实际线性权重行L1与普通1024/2048候选预算；此处独立复核Softmax的异常替代分支与保留原RMS/L2指数范围所需的平方和预算。源码和常量快照哈希、精确整数阈值见同名JSON。没有使用观测最大值当作通用证明。

## 先约束平方和，保留RMS指数范围

令F=2^24，x为f12整数向量，S=Σx_i²为f24整数。当前RMS分母 A=floor(S/d)+16，指数 k=floor(log4(A/F)) 被锁定在[-10,8]。由于A≥16，低端自动满足；高端等价于 A<2^42。整数精确条件是

S≤d(2^42−16)−1。

阈值再增加1就会使floor均值加epsilon达到2^42、导出k=9。因此不能只以S<2^56替代该条件后声称原k范围仍覆盖。d=128/1024/2048对应平方和上限分别见JSON，均严格小于2^56。它允许稀疏大坐标，同时限制向量整体能量；例如统一8192实数坐标上界乘1024维最坏情况给出S=2^60，违反整数预算及原指数范围。

候选可使用坐标上限 floor(sqrt(S_limit))，并在平方前秘密检查、替换域外坐标为0。由此每项平方≤S_limit<2^56。对累加维护secret acc∈[0,S_limit]，先计算room=S_limit−acc，比较term>room，将超额term秘密替换为0、OR进秘密失败位，然后再执行acc+safeTerm。不能先计算可能溢出的候选和再检查，也不能只检查最终环上和。所有循环和通信形状固定，失败位置不公开；域内向量得到原来的精确整数和。后续RMS在失败位下使用一致的dummy路径并保持最终输出失败策略，不能把未检查大值带入平方、barrel shift或线性路径。

这一入域谓词与替代规则改变旧数值域，必须由用户讨论批准后，才由root/models同步规范、R1与R2。当前本记录未改代码。残差相加前的两个来源也需要各自已有范围依据，使相加本身在59位环和2^56预算内；不能把一个运算后的guard当成该运算前提。

对合法RMS输入，floor(S/d)+16>S/d，且A<4F·4^k，因此|x_i·2^(12−k)|<2sqrt(d)F。考虑负数floor后的整数绝对值，取ceil(2sqrt(d)F)+1是保守界。d≤2048时仍小于96F，原scaled检查及NR/Gamma衔接可按现有公式继续分析；这不证明gamma输出落入某一普通域，只给其之前的中间预算。普通域仍需真实量化gamma/线性L1与新的secret检查各自支持。

L2归一化使用未除d的S、原指数[-12,13]，非零整数S的低端自动符合；维持高端则须S≤2^52−1，对应坐标cap=floor(sqrt(2^52−1))=67108863个f12单位。零向量/无效记录先选既定dummy分母和零向量。相同的运算前剩余预算累加方案适用；不能把RMS和L2的S阈值混用。

## Softmax概率和界覆盖当前异常替代分支

以下依据当前三张256项公开exp表每项在[0,F]、第0项恰为F。JSON记录实际逐项扫描结果。这是冻结常量前提，不是任意外部传入表都自动满足的性质。还要求分数已在其既定合法整数域，maximum−score的计算不回绕。

exp_negative的正常分支只把[0,F]表值相乘并floor24，因此输出仍在[0,F]；a<0或a>32的分支返回0。掩码后E_i仍非负且≤F。对存在有效key的行，秘密最大值所来自的项差值为0，E_i=F，因此分母S=ΣE_i处于[F,NF]，N≤1280，求和本身远小于2^56。

query_valid=false时，当前代码秘密改成仅第0项allowed并把全部分数置0，因此S=F。若query_valid=true但没有任何allowed项，seen=false被OR入秘密失败；代码随后强制m[0]=true、x[0]=maximum，其余掩码保持false，仍给S=F。该异常分支维持固定形状，且不会带入零分母。

正常倒数分支令k=floor(log2(S/F))∈[0,10]，满足F·2^k≤S<2F·2^k。每一轮r在使用前经过state检查；最终也经过state，故最终r∈[0,2F]，即使此前NR状态异常被替换为F/2仍成立。倒数编码R=floor(r/2^k)，于是

Σ floor(E_iR/F) ≤ SR/F < 4F。

这个界不依赖NR收敛误差，也不需要声称输出概率和恰等于F。逐项概率若超出[0,F]被替换为0，只会减小非负总和。若单独考虑reciprocal入口的S<F替代分支（上述当前Softmax逻辑已排除它），替代分母F给R≤2F，此时ΣP≤SR/F<2F，仍安全。S>1280F替代分支在E_i≤F且N≤1280的前提下不可能；不能把结论推广到破坏exp表或求和前提的任意输入。

因此对|V_i|≤V_max，任何完整或部分PV累加都满足|ΣP_iV_i|≤ΣP_i|V_i|<4F·V_max。普通V候选1024/2048实数、f12时，原始PV整数绝对值分别严格小于2^48、2^49，仍小于2^56。旧的逐项概率≤F再乘1280这一粗界，在扩大V时可能失败；可直接使用已存在算法的更紧概率和界，无需为PV修改数值规则。应用普通V新域本身仍需要用户批准。

## 结论支持范围

这给出了保留原k扫描范围、允许稀疏离群且仍控制全部中间整数的候选结构，也补齐了普通域扩大时PV的一处容易遗漏的前提。它不证明所有文档/查询都符合这些域，不替代R1/R0观测，也不等于完整R2已运行。当前完整系统仍不可因局部lookup优化或这份解析讨论直接启用。
