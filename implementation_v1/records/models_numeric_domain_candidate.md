# 仅供讨论的 Q/K 运行域修订候选

状态：`PROPOSED_FOR_DISCUSSION_NOT_APPLIED`。下列内容只推导候选，没有修改 NUM-003、R1、R2 或启用配置。真实整数与哈希关联对象见 `models_numeric_domain_candidate.json`。

候选仅给每头 Q/K RMSNorm 输出、其 RoPE 输出/缓存，以及后续 QK 点积和 attention scale 乘法单独定义域。其他主干、Q/K/V 投影输入输出、V、残差和 MLP 仍维持 256。不同 Q、K 上界分开；不能把较大的 K 界也套到 Q 再声称原中间界仍成立。

对 d=128 的每头 RMS，令 A=floor(sum X_j²/128)+16（f24）。因为 A≥sum X_j²/128，且所选 k 满足 A/2^24<4·2^(2k)，缩放向量 B=floor(X·2^(12-k)) 的整数绝对值小于等于 ceil(2√128·2^24)+1=379625064。这个式子已计入负数 floor 的一个整数误差。

可从已定迭代推出比通用 [0,2] 状态域更紧的安全界。写 m=M/2^24∈[1,4)、y=Y/2^24∈[0,2]。两次向下取整使 V/2^24=m y²−δ，0≤δ<5/2^24。下一步实数表达不超过 y(3−m y²)/2+5y/(2·2^24)。前项在非负 y 上的最大值为 1/√m≤1，因此固定每轮输出 Y≤2^24+5=16777221；初值和失败安全替代 1/2 也符合这一界。再逐次计入 H24 和 H12 的负数 floor，归一化、未乘 gamma 的 H12 整数绝对界为 92682。

真实量化 gamma 的全层最大绝对值分别为：Embedding Q=11.8125、K=96.5；Generation Q=9.4375、K=68。将 H12 界逐次乘入真实 gamma 并 floor，得到下表。RoPE 使用实际已生成表的 max(|cos_f20|+|sin_f20|)=1482912，再按已定合并后 floor20 得界。

这些是条件解析上界，明显大于一次观察到的 473；它们覆盖 d=128 正常归一化条件及已定 floor 顺序，不是从少量观测猜测阈值。所有实际判断必须使用 JSON 中的完整 f12 整数，不使用此表六位小数作为判定常量。

最大 Embedding QK 原始 f24 累加界为 2506693996987904。按规范先 floor12，绝对值界变为 611985839109；再乘 f20 attention scale=92681，原始 f32 界为 56719459554461229，小于工程预算 2^56=72057594037927936。Generation 对应两项为 1411230904363008 和 31932200060414491，也低于预算。RoPE 两项合并、私有 gamma 乘法、最终 score 差同样远低于该预算。无需为了这组 Q/K 候选改环位宽或改变已定截断顺序。

这说明一个局部、可审查的修订方向在 Q/K 有关算子的整数范围上成立。它尚未证明整个模型能够正常输出：现在 R1 会在首层把超界 K 替代为 0，因此现有后续执行不能代表采用候选域后的真实激活；采用修订后所有层的投影、残差、MLP 和生成模型仍需重新按既定失败语义核对。权重改动后也须重新登记实际 gamma 界。此处不承诺某个候选足以解决后续所有域失败，也不要求用户盲批一个全局 512。

若讨论通过，应形成明确的新数值配置与规则文本，保持局部域分离，同步 R1/R2 与条件界，再开展相应实现核对。当前配置仍完整保留原来的 256 约束与失败处理。
