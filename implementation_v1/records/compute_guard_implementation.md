## 已实现的接口和行为

- `silu` 的 f12 输入、输出绝对值上界改用 profile 的 `main_abs_f12=2^23`，即实数 2048；指数表、reciprocal、固定六轮 NR 不变。
- `rms(input,gamma,output_abs_f12=main_abs_f12,input_abs_f12=0)` 增加可选公开输入上界。默认 d=128 使用 `min(main_abs_f12,C_128)`，d=1024/2048 使用对应 `C_d`；既有 Q/K 输出专用上界参数兼容。
- `guarded_square_sum` 接收局部加法份额向量及公开坐标/平方和上界，返回同形状局部加法份额、平方和份额、行级失败 XOR 份额。每个坐标先秘密检查并替换，再平方；每一项先与 `limit-sum` 秘密比较并选择，再累加。固定循环结束后，任一行级失败使整行与平方和秘密归零，同时累积全局失败。行级失败与既有全局失败分离，避免用无关行的错误改变当前有效行的计算。
- RMS 有效行仍计算 `A=floor(S/d)+16`；失败行选择 `x=0,A=2^24`，随后以相同公开流程得到 k=0，继续原六轮 NR。L2 在坐标/平方和失败、记录无效、最后有效位无效或 S=0 时使用零向量和 `A=2^24`；仅数值 guard 失败新增 numeric failure，既有无效或零语义不额外报错。

## 运算前边界依据

公开入口校验 `coordinate_cap^2 <= sum_limit < 2^56`，使用除法形式避免公开校验自身溢出。秘密范围检查把非法坐标置零后，实际平方始终在 `[0,limit]`。每步保持 `0<=sum<=limit`，因此 `room=limit-sum` 不下溢；只有 `term<=room` 的项进入加法，实际和不超过 limit。失败位不影响公开循环数或提前返回。
