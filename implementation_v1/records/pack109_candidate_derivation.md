# v1.0.9 候选协议依据（未据此启用生产）

本记录属于当前工程推导，不是用户逐项确认的决定，也不是独立安全审计。成熟且实际接通后才修改规范现行定义。固定模型、修订、环、数值尺度、floor顺序和预算不变。独立参考使用RTX2060；SEAL/SCI只运行隔离密码原语。

## 1. 基线和矩阵输入

`input109_v108_baseline.json`逐阶段、逐算子核对28,180,301份v108输入，与旧静态总计完全相等。主干gamma9,915,264份，Q/K头gamma7,736,064份，合计62.6371166%。Attention QK/PV本身使用共享Beaver乘法，不应把128维gamma误标为Attention矩阵。

对X[B,K]、W[O,K]，B≤16，K≤8192，选公开d∈{16,32,...}且d≤8192/B，s=2d−1。每块输入X_b编码在b*s+j；每输出列W_o反序编码在o*B*s+d−1−j。一个返回密文最多c=min(floor(512/B),floor(8192/(B*d)))个输出列。目标位置为(oB+b)s+d−1。卷积中某个目标只含相同行的同一输出列内积：其他行/列块中心相距s，杂项偏移绝对值≤d−1。完整乘积次数≤Bc*s−1<n，不发生负循环回卷；每权重多项式非零槽数cd≤8192。输入本身可占全部n系数，BFV嵌入误差界不依赖输入非零数。

固定GC外层仍每floor(512/B)列一次，跨多个c1积累本地方相位后统一解码。公开枚举d，最小化实际输入与返回字节ceil(K/d)*1572960+R(d)*786528；尾块同样补零和执行。只有公开维度决定d，没有压缩、按零跳过或秘密形状调度。每返回密文仍全多项式R及fresh Enc(0)，最多512明文积，故原B512及4tB512<q充分条件不变。

Q/K/V在同一个joint调用中拼接输出坐标（2048,1024,1024）；gate/up拼接两份FFN输出。独立80字节大端描述符绑定每个分段，输入只加密一次，输出保留独立份额及原floor节点。不得跨非线性、调用或会话保留输入密文。

gamma采用现有SplitIKNP的一向59位私有乘法：S持w_i，C持x_C,i。S对每位j新鲜采样r_ij，OT消息为−r_ij及2^j*w_i−r_ij；C选择x_C,i的第j位。C取收到消息之和；S取w_i*x_S,i+sum_j r_ij。和严格等于w_i(x_C,i+x_S,i) mod2^59。S只知道自己的输入/掩码，C只得均匀份额；OT保护另一消息及选择。固定每坐标59次OT，没有BFV密文、秘密重构、Beaver打开或隐式floor。

## 2. Token候选：固定19输入，512坐标一个c1

共享Token先按固定18层二进制前缀树形成155648项one-hot算术份额：a2b仅一次，节点通过现有批量Boolean OT相乘，XOR份额b_C,b_S用b_C+b_S−2b_C*b_S转为算术份额。高位非零或索引落在截掉的尾部时全零；生产模型仍先秘密处理真实词表无效索引。全部155648位置和19个输入块固定访问。此阶段通信单独统计，不能藏在“BFV子集”之外宣称整个Token已便宜。

S仍对每隐藏坐标作19个8192项反序多项式乘积并同态相加，但**不发送**这些逐坐标密文。把S的本地内积份额加在8191系数，再乘x^(-8191)，得到目标常数项恰为真实Embedding坐标m_i的密文。其他系数可任意，仍不解密或发送c0。19个输入密文的NTT仅在S本地缓存本次调用，19项乘积先在NTT域相加，再统一逆变换；代数及噪声与逐项逆变换等价。

将512个常数目标密文用9级二叉合并。第l级（l=0..8）令a_l=n/2^(l+1)，g_l=2^(l+1)+1，计算

F=A+x^(a_l)B，G=A−x^(a_l)B，输出Switch_identity(F)+Switch_g_l(G)。

在目标网格j=m*a_l上，g_l作用只产生(−1)^m符号：偶网格只保留2A，奇网格只保留2*x^(a_l)B。自动同构是可逆置换，因此网格外系数不能进入目标网格。归纳得到每级坐标数翻倍、目标值乘2。第9级，坐标i位于32*bitreverse_9(i)，值为512*m_i mod2^59。全部指数按x^n=−1处理；monomial_shift实现符号及模2n索引，不能按普通循环移位。

每tile只返回最终密文c1；H1024/2048分别2/4份。逐坐标内部密文是S本地计算中间物，不能列为网络返回，也不能隐瞒其CPU计算成本。流式栈最多保存10个中间密文，固定511次合并、1022次换钥/tile；不是把512份c1拼成帧。

## 3. 换钥噪声与安全假设

**避免循环换钥假设：**初始秘密钥s0保留为现有BFV输入钥；C另产生9个独立钥s1..s9。第l级只提供从s_l到s_(l+1)的identity和g_l两组RNS换钥。旧钥的自动同构像加密在独立下一把钥下，图严格无环，不提供任何回边、自加密或同钥旋转钥。S只获得辅助公钥/换钥密文，C保留秘密钥。可以按无环次序作普通RLWE/IND-CPA混合论证，不额外假定循环/KDM安全。最终Enc(0)使用s9对应公钥。

实现复用锁定SEAL的`encrypt_zero_symmetric`和`Evaluator::apply_galois_inplace`，按其`generate_one_kswitch_key`相同格式组装不同钥之间的键：每组6个密钥层密文，添加p*CRT_basis_j*σ(s_old)到c0。9级两组共108个密钥层密文，另含终端公钥；未经压缩逐项传输，全部算为每会话初始化，绝不排除后称为“免费离线”。会话结束清理秘密钥，账本不允许复用路径。

锁定密钥层噪声为CBD |e|≤21。SEAL换钥分解有6个系数范围[0,q_j)的整数多项式z_j。密钥层相位为p*σ(c1)*σ(s_old)+sum_j z_j*e_j (mod qp)。每噪声系数绝对值≤6*n*(2^60−1)*21；SEAL除p并逐分量取最近整数额外≤(n+1)/2。因此一次换钥E_KS≤6*n*(2^60−1)*21/p+(n+1)/2<2^24。自动同构/单项式移位只作系数置换及符号翻转。合并时F/G各至多2E，最终≤4E+2E_KS。初始目标完整多项式误差E0<8194*(19*2^71+1)+1（最后1覆盖加S份额）；9级给E9<4^9*E0+2*(4^9−1)/3*2^24。最后掩码与新Enc(0)加8194。必须用实际q检查4*t*(E9+8194)<q；解码代码重复守卫，不借用原B512冒充新界。

## 4. 精确还原和隐私边界

t为2^59，512不是单位，不能声称在明文环内乘512逆元。这里只对Token合法权重使用：规范f12权重绝对值≤2^20，one-hot和全表扫描确保真实目标是一个权重或零，故|512*m_i|≤2^29<2^58，不回绕。GC在秘密状态下还原已遮掩相位对应的59位有符号值，再精确算术右移9位；低9位全零，结果严格m_i，没有舍入误差，也没有更改任何模型floor顺序。这个范围论据不适用于一般矩阵原始累加，Token专用入口不得泛化。

S对最终整个多项式减全环均匀R，再加fresh Enc(0)，只发送c1。C/S分别本地精确分解其相位分量得高部A/B与两位区间。新充分界仍使四门进位k精确。Token专用GC输入C:quarter+A共61位/坐标；S:quarter+(B+R)+rho共120位/坐标。内部计算v=(A+B+R+k) mod2^59，再对其符号扩展右移9位，C只得(v>>9)−rho，S得新鲜全环rho。4门进位+两次59位加法236门+59位减法118门=358AND/坐标。每512目标仍只有一个GC和一次输入OT批次，且普通矩阵保留v108的122门受控返回。没有打开k、联合相位、R、完整Embedding或Token索引。

上述构造只基于已有诚实但好奇两方、BFV/OT/GC假设；源码、有限运行和这份推导不等于全面协议安全认证。模型门禁继续关闭。
