# v1.0.7 私有矩阵协议：实现、依据与适用边界

本记录描述实际实现的矩阵协议，属于工程推导和运行核对，不是正式验收规范或独立安全审计。用户已授权在模型、固定预算、BFV 参数和隐私边界不变的条件下调整协议布局；d=16、B≤16 等具体取值由实施者选择，并非用户逐项指定。矩阵原语的运行不等于完整 Decode 或完整 R2。

## 接口及参与方

`SecureOps::private_matrix(X, O, f_X, f_W, S_reader)` 接收本方 `B×K` 环份额，S 独占 `O×K` 权重，返回本方 `B×O` 环份额。B∈[1,16]、K∈[1,8192]、O∈[1,155648] 均为公开形状，环为 Z/(2^59)。原始输出尺度为 f_X+f_W，不隐式截断。模型投影输入和权重通常 f12，输出 f24；Q/K/V/O、gate/up/down 在完整累加后按原定义 floor12，LM head 保留 f24。Token 选择继续使用另一条固定 19×8192 全扫描协议，其 f0×f12 输出不截断。

权重回调仅在 S 调用，参数为公开 `(begin, actual_columns, first_output, output_count)`，返回 `output_count×actual_columns`；C 不读取权重。回调 shape 错误、描述符不一致或进入协议后的其他异常使会话 abort，断开对端并烧毁材料。公开非法形状在网络操作前拒绝。不会输出相位、权重、未选择系数或完整结果密文。

## 从矩阵到多项式及返回份额

令 d=16、s=2d−1=31，每个输出 tile 有 c≤floor(512/B) 列。第 h 个输入块补零至 16 列：

\[
X_h(z)=\sum_{b=0}^{B-1}\sum_{j=0}^{15}x_{b,16h+j}z^{bs+j},\quad
W_h(z)=\sum_{o=0}^{c-1}\sum_{j=0}^{15}w_{o,16h+j}z^{oBs+15-j}.
\]

第 (b,o) 对占据区间 `[(oB+b)s,(oB+b+1)s−1]`。映射 oB+b 单射，区间互不重叠；目标 `(oB+b)s+15` 仅接收 j=k 的项。因此该系数是完整块点积，其他输入行或输出列均不会串入。最高消息次数 `Bc*31−1≤15871<16384`，无负循环回绕。尾块只将超出 K 的公开位置置零，目标和调度不移动。

C 为各 h 独立加密一次输入份额，缓存后跨公开输出 tile 只读复用。S 对每个输出 tile 的 H=ceil(K/16) 个块依次执行固定形状 RNS 提升、完整 NTT 明文乘法、同层密文相加，得到整个 tile 的累加结果。每个 tile 仅减一次新鲜全 16384 系数均匀环掩码 R，并加一次新鲜 Enc(0)。S 只发送 c1、保留 c0；C 本地计算 c1·sk。每个目标以独立 GC 对象和新鲜标签运行锁定的精确受控解码，返回 C 的份额 `(X_C W^T−R) mod t`；S 保留 `(X_S W^T+R) mod t`。输出存储按 B×O 行优先排列；提取与 GC 顺序固定为 output 再 batch。

这是一个矩阵实例中的多输入行、多输出目标和跨输入块同态合并。无 BatchEncoder、旋转、重线性化、密文乘密文、额外降模或密钥转换；无需生成相应评估密钥。S 的本地份额乘权重仍是本地环运算，不构成对秘密值的重构。

## 条件性正确性与隐私边界

每块 W 至多 c·16≤8192 个系数，中心代表绝对值≤2^58，因此 L1≤2^71。沿用锁定 SEAL CBD/ternary、一次降到第一数据层的界：新鲜零相位误差<8193，消息嵌入误差≤1/2。H≤512 个同层乘积后统一掩码和重随机化，充分界为

\[
B_H=8194(H\cdot2^{71}+1),\quad 1\le H\le512,\qquad 2tB_{512}+1<q.
\]

实际 q 来自锁定上下文，`tools/check_matrix_layout.py` 与 `tools/build_crypto_evidence.py` 用精确整数验证，不依赖浮点估计或抽样噪声。噪声可以负循环回绕、目标之间可以相关，L1 最坏界仍逐系数成立。该界覆盖整个环的随机份额与权重，模型 f12 权重更小。满足构建和执行前提时，有界采样造成的解码失败概率为零；这不等于软件或整个协议安全认证。

复用输入密文不会向 S 增加不同的明文信息；安全前提仍为锁定 BFV/OT/GC 和半诚实参与方。每个 tile 的整个多项式均有独立全环 mask，各输出目标的 mask 系数独立；不能只遮目标。每个目标使用新 GC 对象，OT 流连续且一次性材料不得重用。C 只得到其随机输出份额，不能取 c0 与 c1 自行解密全多项式。维度、块数、返回数量和顺序均公开固定；全零权重仍经过同一 NTT/mask/GC 路径，不按权重、Token、失败位或 EOS 缩短。

本阶段维持原受控返回的安全假设，不新声称电路隐私、恶意安全或经过外部审计。完整模型任意部分和 <2^56 的依据仍由已登记真实权重行 L1 与当前数值域提供，不能用模环解码正确性代替该依据。

## 帧与资源

描述符为 80 字节、10 个大端 uint64：`[PRAGMAT1,1,B,K,O,f_X,f_W,16,floor(512/B),512]`。C 先发送，S 校验后回送同样描述符，C 再校验；在创建本次 BFV 输入之前完成。沿用 PRGCF001 帧的会话、配置、阶段、操作、方向序号和长度绑定，并在 TLS1.3 mTLS 下认证。BFV 不使用 HPKE，不新增 AAD/info。BFV RNS 字节数组仍沿用锁定本机 ABI；不声称跨不同字节序主机兼容。

两方各自的输入密文系数数组上界 `512×2×16384×6×8=805306368` 字节（768 MiB）。这是数组上界，不是进程峰值；密钥、NTT 表、临时乘积、GMP、GC、分配器等另外占用。一次 tile 权重至多 8192 Words，目标至多 512 个；B×O 输出至多 2490368 Words。模型按最多 16 行公共批次调用，不物化词表转置或完整 H×H 对角权重。实测峰值及双向应用字节以各运行 JSON 为准。

每次返回组数为 ceil(O/floor(512/B))，输入密文数 ceil(K/16)，GC 目标数仍为 B·O。报告实际帧数和方向连续段数；方向连续段不是网络 RTT。受控解码仍逐目标执行，不能把一个 tile 误报为一次 GC 或一次网络往返。CPU 执行的是未支持 CUDA 的 SEAL/SCI 独立密码原语，R1 矩阵参考在 RTX 2060；没有运行 CPU 大模型。

当前SCI IKNP每个GC目标的361位输入按16384位块扩展，C发送128个`2048+96`字节帧，S返回`2×361×16+96`字节标签帧，合计286080字节。加上已计入的初始化、门表及允许输出标签，逐目标共2523835字节。单个新会话矩阵的实测帧数按`C_send=128*B*O+ceil(K/16)+259`、`C_recv=39*B*O+ceil(O/floor(512/B))+129`复核；当前串行发送方向连续段为`2*B*O+6`。这些是应用层转录计数，60轮除法是GC内部电路阶段，两者均不能称为实测网络RTT。复核入口`tools/check_matrix_transcript_cost.py`不额外运行协议。

## 模型接线与核对边界

`Transformer::project_many` 接 Q/K/V/O、gate/up/down；同一层公开输入行最多 16 行合并到一个实例。`project`/LM head 复用该入口并保持 f24 输出。RMS 的私有 gamma 以流式公开对角结构接同一协议，规范归一化、NR 和 floor 顺序不改。共享 QK、PV、非线性、比较和 Token 查询继续使用各自所有权匹配的协议。

`tools/run_matrix_protocol.py` 在真实 mTLS、`isolated_development=false` 下调用生产静态库，对比另算的 CUDA R1。诊断输入和权重是公开合成数据；重构只在独立探针内发生，未编入生产库或 worker。小尺寸覆盖批次、非齐尾、全零权重、负数、跨块抵消和超过 FP64 连续整数精度的边界。真实尺寸四例与小例的运行记录分别保存，不把合成权重称作真实 checkpoint 运行。

所有投影接线已编译；完整新 RMS、模型层和 Decode 尚无端到端 R2 执行证据。现有私有 GPU 后端门保持关闭，不以 CPU 全模型、明文模拟或重构替代。完整查询仍有超过十亿个目标 GC；成本脚本单独统计，静态字节子集不是实测全模型性能。

另外，`tools/run_checkpoint_matrix_protocol.py` 已核对锁定生成模型第0层的真实Q投影（2048×2048）与Q gamma（128维对角映射）：S使用worker同一MappedWeights格式、实际文件哈希和行L1检查，C不映射权重。输入为公开合成f12向量，独立CUDA R1与真实mTLS协议raw f24结果逐项一致，分别用时29.4765秒和1.67429秒。这验证两个实际权重映射入口，未运行完整归一化、Attention、层或Decode。证据与源/库绑定见matrix107_checkpoint_runs.json。

四个真实维度合成矩阵（1×2048×2048、1×2048×6144、1×6144×2048、1×2048×151936）已全部完成并与独立CUDA R1逐项一致。词表尺寸一项耗时1885.04秒，双向应用字节383898225473，输入128份密文、返回297份密文、151936次GC。三项小矩阵加四项真实尺寸的转录公式均逐项吻合，见matrix107_transcript_cost_check.json。这里的词表尺寸权重仍是公开合成值，不是完整模型执行。
