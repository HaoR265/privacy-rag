# 目标与项目背景

适用范围：第一版隐私RAG系统。项目角色、术语与功能边界在本文件定义。

## 项目目标

为跨机构知识协作提供单轮证据问答：D 提供资料并指定可使用资料的用户；U 在授权范围内提问；S 持有模型和计算资源、托管受保护数据。问题、资料、Embedding 向量和模型中间值由密码协议保护，只有规定的答案及状态释放给 U。S 私有模型权重不会通过协议交给 U。

## 基本术语

- **RAG（检索增强生成）**：先从授权资料中检索证据，再把选中的证据作为生成模型的输入上下文。
- **Embedding**：模型把一段文本变成定长数值向量，用于相似度检索；本系统通过密码协议保护其输入、输出及中间结果。
- **ACL（访问控制列表）**：资料提供方指定哪些用户可以让该资料参与问答生成。
- **两方秘密分享**：将一个值拆为两份，每方只持有一份；计算在份额上执行，中间值不向单方恢复。
- **HE / BFV**：同态加密及本系统选用的整数同态方案，承担部分共享输入与服务方私有权重的线性计算。
- **OT / GC**：不经意传输与混淆电路，支撑秘密乘法材料、布尔运算及受控解码；具体输入输出由协议契约定义。
- **HPKE / mTLS**：前者封装发给指定用户的资料份额，后者为客户端与服务方建立双向身份认证的传输信道。
- **有效位**：秘密的0/1值，指明一个Token、记录或输出是否应参与计算；物理槽位仍按公开固定形状执行。

## 主体与阶段

| 主体 | 原始秘密与长期状态 | 计算职责 |
| --- | --- | --- |
| D | 原资料、ACL、D侧准备份额、备份 | 本地处理文本，与S私有Embedding，逐用户重新分享与HPKE交付；日常可离线 |
| U | 自己的问题、身份/收包密钥、用户侧随机资料份额 | 全授权同步、与S安全检索和生成、最终恢复回答 |
| S | 模型参数、管理元数据、S侧份额、不可解开的用户包 | 发布、授权快照、托管，与D或U执行两方协议 |

准备阶段和查询阶段各有两在线方。多个进程或三业务角色不能被写成三独立计算方。服务模型方与算力方分离属于后续方向。

## 第一版功能范围

| 设计 | 本版要求 | 边界 |
| --- | --- | --- |
| I1 使用与读取分离 | 授权问答，无原文/向量/命中接口 | 不保证答案语义零披露 |
| I2 跨机构协作 | 跨来源语义检索 | 无结构化秘密联表、PSI |
| I3 证据选择 | 授权集合内秘密Top-2 | 不证明最小充分证据 |
| I4 跨轮披露 | 单轮、无历史上下文、记录查询次数 | 无差分隐私/累计泄漏上界/额外限流承诺 |
| I5 生命周期 | 完整发布、查询快照、撤权对新请求生效 | 不回收已得答案 |
| I6 完整性 | 来源登记、版本与份额配对、HPKE认证检查 | 无零知识证明、恶意S计算可验证性 |
| I7 候选精度 | 保守区间和秘密保留判定，与全N精算核对 | 不做候选压缩/动态跳算，不要求加速 |
| I8 贡献隐藏 | 全同步/全扫描/秘密选择/固定形状 | 不消除既有授权知识与答案语义推断 |

## 非目标

第一版不实现模型训练或微调、重排模型、PIR/ORAM、复杂PDF/OCR、恶意安全、串通安全、密码公平交换、正式多轮泄漏控制、多安全会话并行。不开设普通明文旁路来替代私有模型链。

## 系统组成与文档范围

完整第一版涉及资料准备、逐用户交付、权限快照、问题Embedding、全扫描检索、秘密证据提取、私有生成、最终释放，以及资料更新、撤权和故障恢复。

R0指浮点语义参考，R1指采用既定近似与舍入规则的明文整数功能，R2指保持该整数功能的密码协议实现。三者用于区分计算语义；具体测试内容、方法和验收要求依DEC-008留待后续讨论。本目录整理已有设计，不宣称上述系统已经实现。
