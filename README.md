# 隐私检索增强问答：两方计算实现

本项目实现受授权资料上的隐私检索增强问答。资料准备与授权交付、问题向量计算、全扫描检索、证据装配和生成均已有实现代码。计算采用两方加法秘密分享、BFV 同态加密以及 OT／混淆电路；GPU 加速协议允许的本方份额和密文运算，包括驻留查表、矩阵运算及指定批量的 SiLU 电路。

**当前是研究实现，完整两方问答流程尚未运行成功，正式服务入口保持关闭。** 局部算子匹配整数参考，不代表完整模型、连续生成或问答质量已经验证。本次更新包含已采用的算子优化与有限协议核对说明，没有新增完整模型运行结果。

## 计算方式

- **R0：原模型浮点参考**，用于观察原模型输出。
- **R1：明文定点参考**，执行选定的量化、数值近似和舍入规则。
- **R2：两方隐私计算实现**，在秘密份额和密码协议上实现与 R1 对应的整数计算。

这些名称表示计算实现方式，不是项目阶段。参考模型运行要求 RTX2060，不允许 CPU 回退；密码协议中 CPU/GPU 的具体分工和保留理由见优化说明。

## 源码导航

| 目录 | 功能 |
|---|---|
| `implementation_v1/private_rag/` | 输入准备、授权、HPKE 交付、受保护存储、管理接口与会话调度 |
| `implementation_v1/native/` | BFV、OT、混淆电路、私有查表与矩阵协议 |
| `implementation_v1/compute/` | 模型层、检索、证据装配、生成及本方 CUDA 份额计算 |
| `implementation_v1/references/` | 独立浮点与定点参考 |
| `implementation_v1/model_tools/` | 锁定模型下载、权重量化及参考来源记录 |

| `implementation_v1/artifacts/` | 公开数值常量、模板和 BFV 上下文；不含运行密钥 |

部分目录名保留已有构建 ABI：`hybrid112` 是混合 CPU/GPU 模型诊断，`batch110_baseline` 是开发协议的输入辅助代码；数字不表示完成度。隔离诊断可重构公开夹具结果，只用于开发核对，不进入正式秘密计算入口。
